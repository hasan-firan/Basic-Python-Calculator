# Basic Python Calculator

A simple command-line calculator developed in Python.

## Overview

This project allows users to perform basic arithmetic operations by entering two numbers and selecting a mathematical operator.

The application validates user input, handles invalid values, prevents division by zero, and allows multiple calculations in a single session.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero handling
- Invalid input validation
- Continuous calculation mode
- Modular calculator function

## Technologies

- Python 3
- Functions
- Conditional Statements
- Loops
- Exception Handling
- User Input Validation

## How to Run

1. Make sure Python 3 is installed.
2. Download `Basic-Calculator.py`.
3. Open a terminal in the project folder.
4. Run:

```bash
python Basic-Calculator.py
```

## Example

```text
select first number: 10
select second number: 5
select an operation: *
result: 50

continue to another order? Y/N:
```
